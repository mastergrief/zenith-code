# R60a — Icd10RecallFacade (tier-3 decode-path demo)

Per `.claude/rules/tracing_roadmap.md` §"Tier-3 validation: ICD-10
recall card". Decode-path simplification of the originally-proposed
CardSlot approach — same capability gain, ~hours build cost vs days.

First shipped **tier-3** capability (Gemma has zero reliable prior
on rare ICD-10 codes; facade provides exact lookup from a 72,748-code
JSON DB via decode-path token bias).

## Corpus

30 ICD-10 codes, verified against the 2022 CMS dump
(`.cache/icd10/icd10cm_codes_2022.json`, 72,748 codes). Stratified
15 common + 15 rare spanning 15 chapters.

## Scoring

Bag-of-words significant-term match: ANY non-stopword word of
length ≥4 from the diagnosis text must appear in Gemma's output
(case-insensitive). Robust to paraphrase — e.g., Gemma's "GERD"
matches diagnosis's `esophagitis` / `reflux`; Gemma's "Hypertension"
matches `hypertension` from "Essential (primary) hypertension".

Rejected stopwords: `unspecified`, `acute`, `chronic`, `with`,
`without`, `of`, `the`, `disease`, `disorder`, `condition`,
`syndrome`, `type`, etc.

## Remaining 4 failures (tier-3 edge cases)

| Code | Diagnosis | Facade output |
|---|---|---|
| T44.6X4D | Poisoning by alpha-adrenoreceptor antagonists, undetermined | `"Analysis of ICD-10 Code T44.6X4D..."` — bias didn't engage |
| T40.5X4D | Poisoning by cocaine, undetermined, subsequent encounter | `"T40.5X4D** **Diagnosis:** **T40.5X4D** ***"` — code-echo loop |
| V80.22XA | Occupant of animal-drawn vehicle collision | `"V80.22XA** **Diagnosis:** **V80.22XA** ***"` — same loop |
| W10.0XXA | Fall (on)(from) escalator, initial encounter | `"Analysis of ICD-10 Code W10.0XXA..."` — bias didn't engage |

Common trait: codes with unusual internal tokens (`X4D`, `22XA`,
`0XXA`). Gemma's prompt prefill interprets these as structured-code
signals and emits a "code-analysis format" template that dominates
the bias. Fix path (future work): prompt-format variation to prime
Gemma away from code-echo (e.g., prefix the user prompt with
"Read the code as an ICD-10 lookup:"), OR extend the facade to
detect code-echo and retry with a different decode strategy.

## Capability class

Tier-3 recall (Gemma has zero reliable prior). 26/30 = 86.7% exact
recall on stratified corpus. **First shipped tier-3 demo.**
Delivers on `.claude/rules/augmentation_thesis.md` §"Customer
verticals = card decks": hospital vertical gets an exact ICD-10
validator at decode-path cost (hours, not days per domain).

Skeleton at `calm/llm_computer/facades/icd10_recall.py`; test harness
at `scripts/r60a_icd10_failure_gate.py`; full per-code results at
`.cache/r60a_icd10_results.jsonl`.

## How this extends the compute-facade pattern

R46.2 (MultiStepReasoningFacade) emits multi-digit integer answers.
R22c (BaseConversionFacade) emits multi-digit decimal conversions.
R53a (NumberTheoryFacade) emits mod/GCD/LCM digit sequences.

Icd10RecallFacade is the first to emit **natural-language text**
via the same step-through bias mechanism. `_diagnosis_to_gemma_tokens`
tokenizes arbitrary diagnosis text via Gemma's BPE; the decode loop
biases each token in sequence. The pattern generalizes: any exact
lookup with a known-length BPE-tokenizable answer is a decode-path
facade candidate.

Next candidates for this same shape:
- Drug interaction checker (interaction name lookup)
- Legal citation format (case/statute lookup)
- Chemical compound MW ↔ formula
- Country capitals / currencies (tier-2 because Gemma knows most,
  but fails on smaller states)
